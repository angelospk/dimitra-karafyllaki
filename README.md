# dimitra-karafyllaki

Static site for Dimitra Karafyllaki, Dietitian-Nutritionist MSc (Thessaloniki).
Plain HTML/CSS/JS, no build step. Hosted on Vercel.

- Contact data, hours and reviews come from her Google Maps listing (October 2026).
- `#about` holds placeholder text until the CV arrives (see the TODO in `index.html`).
- Opening hours live in two places: the table in `index.html` and `HOURS` in `main.js`.

Local preview: `python3 -m http.server 8765`
